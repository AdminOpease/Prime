## ✏️ Common things you'll do

### 1. Change opening hours

1. Open the Studio
2. Left sidebar → **Site Settings**
3. Click the **Opening Hours** tab
4. Change the times → click **Publish** (bottom right)

Changes appear on the website within about 1 minute.

### 2. Change the phone number, email, or address

1. Studio → **Site Settings**
2. Click the **Contact** tab
3. Edit → **Publish**

### 3. Update the About page

1. Studio → **Pages**
2. Click the **About** page (or create one if it doesn't exist yet)
3. Edit the body content → **Publish**

### 4. Add a new service

1. Studio → **Services** → **+ Create** (top right)
2. Fill in title, short description, longer body, and category
3. Upload a hero image (a phone photo is fine — Sanity resizes it)
4. Set `Show on homepage` if you want it in the top strip
5. **Publish**

### 5. Add a before-and-after gallery photo

1. Studio → **Gallery** → **+ Create**
2. Give it an internal title (e.g. "Ford Transit rear panel — Jan 2026")
3. Upload the **Before** and **After** photos
4. Optional: pick which service it relates to, add a caption
5. **Publish**

### 6. Add a customer review

1. Studio → **Testimonials** → **+ Create**
2. Type in the customer's name and their words
3. Set a star rating (1–5)
4. Tick "Show on homepage" if you want it in the reviews section
5. **Publish**

### 7. Change the logo

1. Studio → **Site Settings** → **Branding** tab
2. Click the current logo → upload a new one
3. **Publish**

## 📷 Photo tips

- **Phone photos are perfect.** Just take them in good light and Sanity
  will resize them for the website automatically.
- **Try to shoot before AND after** on the same angle for gallery photos —
  they look great side-by-side.
- **Full-vehicle photos** work best for services (car parked outside the
  unit, side-on, well-lit).

## ⚠️ What to leave alone

Don't touch these unless we've talked about it:

- **Homepage → Featured Services** — this changes the homepage layout;
  ask before rearranging
- **Pages → slug** — changes the URL, breaks any old links
- **Service → slug** — same as above

If you're not sure whether to change something, message me first.

## 📥 What happens when someone requests an estimate on the website?

You'll get an email at **eduard@primebodywork.co.uk** the moment they
submit the form. It looks like:

> **Subject:** Estimate request — [reg] — [customer name]
>
> Includes: name, phone, email, registration, damage location, timescale,
> vehicle driveable Yes/No, plus any photos they uploaded.

You can **reply directly** to that email and it goes back to the customer.
